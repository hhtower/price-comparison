# 导购能力资料

导购根据人工核验的官方资料匹配用途，不在运行时抓取官方页面。资料、来源及复核日期统一维护在 [assistant-capabilities.ts](../apps/api/src/assistant/assistant-capabilities.ts)，本文件不重复列出。

## 资料维护

- 新增或更新资料时，核对官方来源中的套餐、功能及地区、年龄、额度等限制，同步更新用途词、功能说明、来源和复核日期。
- 到达复核日期后，该资料不再用于用途推荐；明确指定平台或商品仍可查询报价。报价过期与能力资料过期是两种规则。
- 产品身份使用标准家族、产品和套餐组合，并区分适用的会员商品特性；不使用部署数据库 ID，也不凭商家宣传推断身份。

## 推荐边界

报价是采集时的参考快照，允许过期、预估、未核验及陈旧数据，不以库存状态筛除，也不在生成回复后重新查询。保留采集时间，实际价格、库存和售后以商家为准。

候选仍须满足公开目录可见性、有效金额及币种、单件购买、用户预算和明确购买条件。质保和购买条件必须来自同一报价；缺失或冲突的信息视为未知。不同币种和期限不直接比价，不自动换汇或将年价折算为月价。

AI 会员的新手推荐默认只查询成品号和代充，并满足用户的预算及购买条件；结果不足时不补入短期。用户明确选择其他类别或关闭新手模式时遵从其选择。其他商品不应用这项限制。质保标签只展示明确时长或保障范围。

仅检索部分目录候选，不承诺全网最低价或覆盖所有方案，不以其他套餐替代指定商品。

用途匹配依赖有限词表，不能自行理解否定、地区资格或复杂组合要求；不明确时应澄清。官方套餐功能不代表商家的共享账号或特定使用入口必然支持。

## 维护约束

通过目录服务解析公开商品身份，保留其返回的平台分组和身份名称；这些内部元数据不对外暴露。查询具体报价，避免目录预览合并商家报价后遗漏符合条件的商品。

商家文字属于不可信数据，模型只能引用对应候选的真实证据。保留质保限制；说明过长时提示查看完整条款，不截断成承诺。筛选、排序、响应字段及长度限制以 [候选逻辑](../apps/api/src/assistant/assistant-candidates.ts)、[导购服务](../apps/api/src/assistant/assistant.service.ts)和[响应契约](../packages/catalog/src/assistant-contract.ts)为准。

验证与部署要求见 [WORKFLOW.md](../WORKFLOW.md)。

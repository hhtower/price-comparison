# 助手能力与限制

助手支持相关知识咨询、公开目录统计、价格历史和报价推荐。可以先了解分类、继续追问，再进入选购；询问知识或统计不会改变已确认的购买条件。不承诺覆盖所有方案或找到全网最低价。

## 咨询与数据

- 按“直接回答 → 必要解释 → 必要追问”按需推进，每轮一至三条短消息，说清楚就结束。若缺少关键信息，先问清楚，等待用户回复后继续；不机械凑满三条。完整依据与统计口径可展开查看。
- 商品分类、保障和标签解释依据本站选购指南，可组合比较并在回答下查看来源。本站“短期”还包括保障或交付方式不明确的商品，不等于单纯的会员使用期限。
- 数量查询区分公开标准商品、报价和采集覆盖，支持按会员类别或平台分组。全站查询不继承购买预算；“按刚才条件”沿用已确认条件，本次临时筛选不修改购买需求。
- 统计默认按人民币公开目录查询，其他币种须明确指定。统计结果说明范围、币种和查询时间；目录有缓存，分组读取不保证同一数据库快照。公开目录计数不等于通过全部推荐资格核验的报价数。
- 历史查询须能唯一确定商品，显示已有的每日最低已核验结算总价记录。缺测日期不补值，不把不同商家、规格、数量或期限的记录解释成同一报价涨跌；历史接口不支持的预算和标签条件不会被忽略。
- 暂不支持均价、占比、价格分布、自由联网搜索或管理数据查询。无数据、资料过期或服务不可用时会说明限制。
- 查询数字由服务端事实提供，来源由程序生成；自然语言解释仍可能误解资料，来源有效不等于结论必然正确。涉及购买时请核对原始条款。

## 推荐边界

- 用途推荐依据人工核验的官方资料。资料过期后暂停对应用途推荐，明确指定平台或商品仍可查询报价。
- AI 会员默认推荐成品号和代充。ChatGPT Plus 的代充区分“通用”和“半价资格”，其他会员显示“代充”；搜索“代充”覆盖其全部分支。通用不表示没有其他购买限制。用户明确选择其他类别或关闭新手范围时遵从其选择，不以其他类别或套餐补足结果。
- 报价可能已过期、未核验或缺货。价格、库存与售后以商家为准，官方套餐功能也不代表商家提供的账号或入口必然支持。
- 预算和购买条件须由同一报价满足。不同币种和期限不直接比价，不自动换汇或将年价折算为月价；月预算仅匹配精确 30 天的报价。
- 强制多件或打包销售不作为单件报价推荐。支持批量不等于必须批量购买，批量标签不能证明结算数量。
- 订阅保障和使用保障分别核对，不从保障文本推算最低质保天数或长短排名。缺失、冲突及免责条件不能解释为保障承诺。
- 用途识别的覆盖有限，复杂或不明确的要求需要澄清。筛选规则变化后，旧条件失效时保留聊天记录，并提示重新说明需求。

## 资料维护

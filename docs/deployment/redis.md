# Redis 运行配置

Redis 用于登录会话、目录缓存和分布式限流，不代替业务数据库。通过 `REDIS_URL` 配置连接，使用 TLS 时采用 `rediss://` 地址。

## 配置与监控

- 限制网络访问并配置认证；不同环境使用独立实例或隔离配置。
- 根据负载设置内存上限和淘汰策略。认证与限流也依赖 Redis，不能只按缓存容量规划。
- 关注内存、连接数、命令延迟、淘汰和被拒绝的连接。
- 环境变量见 [.env.example](../../.env.example)，不要在日志或监控标签中保存密钥、Cookie 或令牌。

## 故障与恢复

目录缓存不可用时可回源数据库，但登录和限流功能仍可能受影响。数据库可用不代表 Redis 相关功能正常。

清理认证会话会使用户重新登录，不要将清空 Redis 当作普通缓存刷新。恢复后检查登录、目录访问和限流功能；业务数据恢复以 PostgreSQL 为准。
